Java 基础特性

【Java 基础特性】专题涵盖语言核心语法、类型系统、面向对象三大范式、控制流与异常体系，以及泛型、反射、注解等运行时机制。这些是 Java 开发的基石，深入理解有助于编写健壮、可维护的代码，也是面试高频考察点。

  • Java 基础语法特性 - 关键词：强类型、访问修饰符、final、操作符、序列化
  • Java 基本数据类型 - 关键词：包装类、装箱拆箱、缓存机制、BigDecimal、精度丢失
  • Java 面向对象 - 关键词：封装、继承、多态、接口、抽象类
  • Java 方法 - 关键词：值传递、重载、覆写、static、可变参数
  • Java 数组 - 关键词：引用类型、多维数组、Arrays、长度固定、下标
  • Java 枚举 - 关键词：enum、EnumSet、EnumMap、单例模式、状态机
  • Java 控制语句 - 关键词：if、switch、while、for、break
  • Java 异常 - 关键词：Throwable、RuntimeException、try-catch-finally、Checked Exception、异常链
  • Java 泛型 - 关键词：类型擦除、通配符、PECS、泛型类、类型边界
  • Java 反射 - 关键词：Class、invoke、动态代理、CGLIB、InvocationHandler
  • Java 注解 - 关键词：元注解、@Retention、@Target、自定义注解、反射解析
  • Java String 类型 - 关键词：不可变、字符串常量池、intern、StringBuilder、StringBuffer

Java 高级特性

【Java 高级特性】专题涵盖正则表达式引擎、编解码与密码学、国际化、SPI 服务发现机制、JavaAgent 字节码增强以及 JDK8 函数式编程范式。这些进阶内容为构建高性能、可扩展的企业级应用提供了关键支撑，也是区分初中级与高级工程师的重要知识域。

  • Java 正则 - 关键词：Pattern、Matcher、捕获与非捕获、零宽断言、贪婪与懒惰

  • Java 国际化 - 关键词：Locale、ResourceBundle、NumberFormat、DateFormat、MessageFormat
  • Java SPI - 关键词：SPI、ServiceLoader、ClassLoader、扩展点
  • JavaAgent - 关键词：Instrumentation、premain、ClassFileTransformer、字节码增强、JVMTI
  • Java JDK8 - 关键词：Stream、Lambda、Optional、@FunctionalInterface

Java 容器

【Java 容器】专题以 Collection 和 Map 两大体系为核心，涵盖 List、Set、Queue 等经典数据结构及其底层实现原理（数组、链表、红黑树、哈希表）。结合 Stream API 的声明式数据处理能力，构成 Java 日常开发中数据组织、操作与转换的完整工具链，是面试中考察数据结构与算法功底的核心阵地。

  • Java 容器简介 - 关键词：Collection、Map、Iterator、Comparator、fail-fast
  • Java 容器之 List - 关键词：ArrayList、LinkedList、动态扩容、RandomAccess、subList
  • Java 容器之 Map - 关键词：HashMap、LinkedHashMap、TreeMap、红黑树、负载因子
  • Java 容器之 Set - 关键词：HashSet、LinkedHashSet、TreeSet、去重、NavigableSet
  • Java 容器之 Queue - 关键词：Deque、ArrayDeque、PriorityQueue、BlockingQueue、二叉堆
  • Java 容器之 Stream - 关键词：Stream、中间操作、终结操作、Collector、惰性求值

Java IO

【Java IO】专题涵盖 Java 输入输出体系的核心知识，包括 BIO（同步阻塞）、NIO（多路复用）、AIO（异步非阻塞）三种 IO 模型的原理与实践。同时深入序列化与反序列化机制，涉及 JDK 原生序列化、Protobuf、Hessian 等主流方案的对比与应用。

  • Java IO 之 简介 - 关键词：BIO、NIO、AIO、I/O 多路复用、Reactor
  • Java IO 之 BIO - 关键词：BIO、字节流、字符流、InputStream、Socket
  • Java IO 之 NIO - 关键词：NIO、Channel、Buffer、Selector、零拷贝
  • Java IO 之序列化 - 关键词：Serializable、serialVersionUID、transient、Protobuf、JSON

Java 并发

【Java 并发】专题系统梳理多线程并发编程的核心知识体系，涵盖 Java 内存模型（JMM）、线程生命周期与同步机制、锁机制（synchronized/ReentrantLock/AQS）、无锁并发（CAS/原子类/ThreadLocal）等核心主题。同时深入线程池原理、并发容器、同步与分工工具类等实战内容，帮助理解并发编程的本质问题与解决方案。

  • Java 并发简介 - 关键词：原子性、可见性、有序性、死锁、上下文切换
  • Java 并发之内存模型 - 关键词：JMM、Happens-Before、volatile、synchronized、锁升级
  • Java 并发之线程 - 关键词：Thread、Runnable、Callable、线程生命周期、interrupt
  • Java 并发之锁 - 关键词：ReentrantLock、AQS、CAS、悲观锁、乐观锁
  • Java 并发之无锁 - 关键词：CAS、原子类、ThreadLocal、ABA 问题、Copy-on-Write
  • Java 并发之 AQS - 关键词：AQS、CLH 队列、独占锁、共享锁、Condition
  • Java 并发之容器 - 关键词：ConcurrentHashMap、CopyOnWriteArrayList、BlockingQueue、分段锁、CAS
  • Java 并发之线程池 - 关键词：ThreadPoolExecutor、corePoolSize、拒绝策略、workQueue、Executors
  • Java 并发之同步工具 - 关键词：CountDownLatch、Semaphore、CyclicBarrier、信号量、AQS
  • Java 并发之分工工具 - 关键词：CompletableFuture、ForkJoinPool、FutureTask、工作窃取、异步编排

Java 虚拟机

【Java 虚拟机】专题深入剖析 JVM 的核心运行机制，涵盖运行时数据区（堆、栈、方法区）、垃圾收集算法与主流收集器（CMS、G1、ZGC）、字节码格式与类加载机制（双亲委派模型）等关键主题。同时涉及 JVM 性能调优方法论与常用诊断工具（Arthas、jstat、jmap、MAT），助力生产环境问题排查与性能优化。

  • Java 虚拟机简介 - 关键词：JVM、Hotspot、运行时数据区、类加载器、JIT
  • Java 虚拟机之内存区域 - 关键词：堆、方法区、元空间、虚拟机栈、OutOfMemoryError
  • Java 虚拟机之垃圾收集 - 关键词：GC Roots、可达性分析、分代收集、CMS、G1
  • Java 虚拟机之字节码 - 关键词：字节码、常量池、字节码指令、ASM、ByteBuddy
  • Java 虚拟机之类加载 - 关键词：类加载机制、双亲委派、ClassLoader、热部署、SPI
  • Java 虚拟机之工具 - 关键词：Arthas、jstat、jmap、jstack、MAT
  • Java 虚拟机之故障处理 - 关键词：CPU 飙升、内存泄漏、OOM、GC 频繁、死锁
  • Java 虚拟机之调优 - 关键词：-Xms、-Xmx、GC 日志、吞吐量、停顿时间

JavaWeb

安全

Java 领域比较流行的安全框架就是 Shiro 和 Spring-Security。

Shiro 更为简单、轻便，容易理解，能满足大多数基本安全场景下的需要。

Spring-Security 功能更丰富，也比 Shiro 更复杂。值得一提的是由于 Spring-Security 是 Spring 团队开发，所以集成 Spring 和 Spring-Boot 框架更容易。

  • Shiro - 关键词：Shiro、认证、授权、Realm、会话管理
  • SpringSecurity - 关键词：Spring Security、安全框架、认证授权、FilterChain、OAuth2
