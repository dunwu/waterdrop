# 设计模式

> **设计模式**是软件设计中常见问题的典型解决方案。

- [设计模式概述](设计模式概述.md)

- [设计模式面试](设计模式面试.md) 💯

### 创建型模式

> 创建型模式提供了创建对象的机制， 能够提升已有代码的灵活性和可复用性。

- [简单工厂模式 (Simple Factory)](简单工厂模式.md) - 关键词：`简单工厂`、`工厂类`、`产品类`、`创建型`、`switch-case`
- [工厂方法模式 (Factory Method)](工厂方法模式.md) - 关键词：`工厂方法`、`创建型`、`Creator`、`Product`、`子类决定实例化`
- [抽象工厂模式 (Abstract Factory)](抽象工厂模式.md) - 关键词：`抽象工厂`、`创建型`、`产品族`、`AbstractFactory`、`跨平台 UI`
- [建造者模式 (Builder)](建造者模式.md) - 关键词：`建造者`、`Builder`、`创建型`、`Director`、`分步构建复杂对象`
- [原型模式 (Prototype)](原型模式.md) - 关键词：`原型`、`Prototype`、`创建型`、`Cloneable`、`深浅拷贝`
- [单例模式 (Singleton)](单例模式.md) - 关键词：`单例`、`Singleton`、`创建型`、`getInstance`、`私有构造函数`

### 结构型模式

> 结构型模式介绍如何将对象和类组装成较大的结构， 并同时保持结构的灵活和高效。

- [适配器模式 (Adapter)](适配器模式.md) - 关键词：`适配器`、`Adapter`、`结构型`、`接口转换`、`不兼容对象协作`
- [桥接模式 (Bridge)](桥接模式.md) - 关键词：`桥接`、`Bridge`、`结构型`、`抽象与实现分离`、`多维度扩展`
- [组合模式 (Composite)](组合模式.md) - 关键词：`组合`、`Composite`、`结构型`、`树形结构`、`部分-整体`
- [装饰模式 (Decorator)](装饰模式.md) - 关键词：`装饰`、`Decorator`、`结构型`、`动态添加职责`、`替代继承`
- [外观模式 (Facade)](外观模式.md) - 关键词：`外观`、`Facade`、`结构型`、`统一接口`、`简化子系统`
- [享元模式 (Flyweight)](享元模式.md) - 关键词：`享元`、`Flyweight`、`结构型`、`共享对象`、`内存优化`
- [代理模式 (Proxy)](代理模式.md) - 关键词：`代理`、`Proxy`、`结构型`、`访问控制`、`虚拟代理`

### 行为型模式

> 行为模式负责对象间的高效沟通和职责委派。

- [模板方法模式 (Template Method)](模板方法模式.md) - 关键词：`模板方法`、`Template Method`、`行为型`、`算法骨架`、`基本方法`
- [命令模式 (Command)](命令模式.md) - 关键词：`命令`、`Command`、`行为型`、`请求封装`、`撤销操作`
- [迭代器模式 (Iterator)](迭代器模式.md) - 关键词：`迭代器`、`Iterator`、`行为型`、`遍历集合`、`隐藏内部结构`
- [观察者模式 (Observer)](观察者模式.md) - 关键词：`观察者`、`Observer`、`行为型`、`发布-订阅`、`事件通知`
- [解释器模式 (Interpreter)](解释器模式.md) - 关键词：`解释器`、`Interpreter`、`行为型`、`文法解析`、`Context`
- [中介者模式 (Mediator)](中介者模式.md) - 关键词：`中介者`、`Mediator`、`行为型`、`解耦对象交互`、`集中协调`
- [职责链模式 (Chain of Responsibility)](职责链模式.md) - 关键词：`职责链`、`Chain of Responsibility`、`行为型`、`处理者链`、`请求传递`
- [备忘录模式 (Memento)](备忘录模式.md) - 关键词：`备忘录`、`Memento`、`行为型`、`状态快照`、`撤销恢复`
- [策略模式 (Strategy)](策略模式.md) - 关键词：`策略`、`Strategy`、`行为型`、`算法族`、`运行时切换`
- [访问者模式 (Visitor)](访问者模式.md) - 关键词：`访问者`、`Visitor`、`行为型`、`双重分派`、`对象结构操作`
- [状态模式 (State)](状态模式.md) - 关键词：`状态`、`State`、`行为型`、`状态转换`、`行为随状态改变`
