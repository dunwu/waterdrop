### 设计模式

- [面向对象原则](设计模式/面向对象原则.md) - 关键词：`SOLID`、`单一职责`、`开闭原则`、`里氏替换`、`依赖倒置`

#### 创建型模式

> 创建型模式提供了创建对象的机制， 能够提升已有代码的灵活性和可复用性。

- [单例模式 (Singleton)](设计模式/单例模式.md)：全局唯一实例 - 关键词：`单例`、`Singleton`、`创建型`、`getInstance`、`私有构造函数`
- [简单工厂模式 (Simple Factory)](设计模式/简单工厂模式.md)：通过一个工厂类根据参数创建不同产品对象，将创建逻辑集中封装，客户端无需了解具体实现 - 关键词：`简单工厂`、`工厂类`、`产品类`、`创建型`、`switch-case`
- [工厂方法模式 (Factory Method)](设计模式/工厂方法模式.md)：子类决定创建哪个对象 - 关键词：`工厂方法`、`创建型`、`Creator`、`Product`、`子类决定实例化`
- [抽象工厂模式 (Abstract Factory)](设计模式/抽象工厂模式.md)：创建相关或依赖的产品族 - 关键词：`抽象工厂`、`创建型`、`产品族`、`AbstractFactory`、`跨平台 UI`
- [建造者模式 (Builder)](设计模式/建造者模式.md)：分步构建复杂对象 - 关键词：`建造者`、`Builder`、`创建型`、`Director`、`分步构建复杂对象`
- [原型模式 (Prototype)](设计模式/原型模式.md)：克隆生成对象 - 关键词：`原型`、`Prototype`、`创建型`、`Cloneable`、`深浅拷贝`

#### 结构型模式

> 结构型模式介绍如何将对象和类组装成较大的结构， 并同时保持结构的灵活和高效。

- [代理模式 (Proxy)](设计模式/代理模式.md)：控制对象访问 - 关键词：`代理`、`Proxy`、`结构型`、`访问控制`、`虚拟代理`
- [装饰模式 (Decorator)](设计模式/装饰模式.md)：动态添加职责 - 关键词：`装饰`、`Decorator`、`结构型`、`动态添加职责`、`替代继承`
- [适配器模式 (Adapter)](设计模式/适配器模式.md)：接口转换，兼容不匹配类 - 关键词：`适配器`、`Adapter`、`结构型`、`接口转换`、`不兼容对象协作`
- [桥接模式 (Bridge)](设计模式/桥接模式.md)：抽象与实现分离，独立变化 - 关键词：`桥接`、`Bridge`、`结构型`、`抽象与实现分离`、`多维度扩展`
- [组合模式 (Composite)](设计模式/组合模式.md)：树形结构表示整体-部分 - 关键词：`组合`、`Composite`、`结构型`、`树形结构`、`部分-整体`
- [外观模式 (Facade)](设计模式/外观模式.md)：为子系统提供统一接口 - 关键词：`外观`、`Facade`、`结构型`、`统一接口`、`简化子系统`
- [享元模式 (Flyweight)](设计模式/享元模式.md)：共享细粒度对象，节省内存 - 关键词：`享元`、`Flyweight`、`结构型`、`共享对象`、`内存优化`

#### 行为型模式

> 行为模式负责对象间的高效沟通和职责委派。

- [模板方法模式 (Template Method)](设计模式/模板方法模式.md)：算法骨架，子类实现步骤 - 关键词：`模板方法`、`Template Method`、`行为型`、`算法骨架`、`基本方法`
- [策略模式 (Strategy)](设计模式/策略模式.md)：算法可替换 - 关键词：`策略`、`Strategy`、`行为型`、`算法族`、`运行时切换`
- [观察者模式 (Observer)](设计模式/观察者模式.md)：一对多通知依赖者 - 关键词：`观察者`、`Observer`、`行为型`、`发布-订阅`、`事件通知`
- [状态模式 (State)](设计模式/状态模式.md)：状态改变行为 - 关键词：`状态`、`State`、`行为型`、`状态转换`、`行为随状态改变`
- [职责链模式 (Chain of Responsibility)](设计模式/职责链模式.md)：请求沿链传递，多处理器 - 关键词：`职责链`、`Chain of Responsibility`、`行为型`、`处理者链`、`请求传递`
- [命令模式 (Command)](设计模式/命令模式.md)：请求封装为对象，支持操作队列 - 关键词：`命令`、`Command`、`行为型`、`请求封装`、`撤销操作`
- [迭代器模式 (Iterator)](设计模式/迭代器模式.md)：顺序访问聚合元素 - 关键词：`迭代器`、`Iterator`、`行为型`、`遍历集合`、`隐藏内部结构`
- [中介者模式 (Mediator)](设计模式/中介者模式.md)：封装对象间交互，降低耦合 - 关键词：`中介者`、`Mediator`、`行为型`、`解耦对象交互`、`集中协调`
- [访问者模式 (Visitor)](设计模式/访问者模式.md)：在不改变元素类前提下增加新操作 - 关键词：`访问者`、`Visitor`、`行为型`、`双重分派`、`对象结构操作`
- [备忘录模式 (Memento)](设计模式/备忘录模式.md)：保存和恢复对象状态 - 关键词：`备忘录`、`Memento`、`行为型`、`状态快照`、`撤销恢复`
- [解释器模式 (Interpreter)](设计模式/解释器模式.md)：定义并解释文法 - 关键词：`解释器`、`Interpreter`、`行为型`、`文法解析`、`Context`
