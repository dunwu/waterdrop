# JavaWeb

> JavaWeb 专题围绕 Java EE Web 层开发的核心技术栈，系统梳理 Servlet 容器模型与生命周期、JSP 动态页面渲染、Filter 与 Listener 扩展机制、Cookie/Session 会话管理等经典主题。这些技术构成了 Spring MVC 等现代框架的底层规范基础，深入理解有助于把握 Web 应用的请求处理链路与状态管理本质。
